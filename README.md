# 築考 Lab｜建築師專技考試模擬測驗

以考選部公開考畢試題為主要來源，提供建築師專技考試題庫瀏覽與模擬測驗。

## 使用方式

直接開啟 `index.html` 即可使用，不需要安裝伺服器或套件。

模擬試卷依正式考試題數生成，年度配題規則為：

- 近 8 年：50%
- 第 9～16 年：35%
- 其餘年度：15%

完整檢核與答案來源說明請參考專案內的 Markdown 文件。舊年度若沒有考選部標準答案，不會未經核對直接加入自動評分題庫。

資料來源：[考選部考畢試題查詢平台](https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx?y=2025&e=114180)
